AmbitionBox Company Web Scraper (Pune City)

A Python-based web scraper that collects company details such as company name, reviews, salaries, interviews, jobs, benefits, and photos from AmbitionBox (Pune companies list) and saves the data into a CSV file.

---

🚀 Features
- Scrapes multiple pages (adjustable)
- Extracts:
  - Company Name  
  - Reviews Count  
  - Salaries Count  
  - Interviews Count  
  - Jobs Count  
  - Benefits Count  
  - Photos Count  
- Saves data into companies.csv
- Avoids duplicates
- Can be extended with proxies (e.g., ScraperAPI)
- Simple and beginner-friendly code

---

Analysis of data using :-

[1] Pandas
[2] Numpy
[3] Matplotlib

-- Worked on converting datatypes to the required format
-- Removing inaccurate data and replacing values
-- Visualization using matplotlib
